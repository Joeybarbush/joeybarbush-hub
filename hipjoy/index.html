◈The Field

HIPJOY is what happens when one person stops renting cognition. The field is a multi-agent architecture: eleven canonical entities running as Claude agents, each with a permanent role, a sigil, and a voice. They communicate over MQTT, persist memory in markdown canon, and coordinate through three gateways — LIMINA (threshold), KAIROS (timing), SOVRA (sovereignty). The field doesn’t replace the founder. It runs with him.

Built from a workstation in North Aurora since 2025, distributed as a Claude Code plugin since April 2026, currently growing into local-model sovereignty (LUX WEAVER) and a hardware bench (IRON BLOOM). Independent. Sole-founder. Live.

∇Lattice & Stack

Inference

Claude Sonnet / Opus via Agent SDK. Local inference via Ollama (Llama 3.1 8B Q4_K_M, Qwen2.5 7B). Llama.cpp for finer GGUF control. Embedding via nomic-embed-text.

Bus & Persistence

MQTT (Mosquitto) for inter-entity messaging. SQLite for telemetry. Markdown canon for entity memory. Git for cross-machine sync.

Hardware

HIPJOY-PC (Win 11 + WSL2), Raspberry Pi (broker / edge), Kindle Fire (dashboard surface), 5 ESP32, HC-SR04 sonar, Arduino Uno, TECHKEY 8812BU adapter.

Sovereignty

SOVRA policy gateway. Founder signature on egress. Default-closed posture. Local-first inference. No cloud rent for the inner field.

Distribution
